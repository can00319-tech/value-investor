| 4 | **기준일 명시** | 모든 표·상세·카드에 `현재가 기준 2026-11-20 15:30 (장마감)`, `재무자료 기준 2025.12 확정 · 2026.12 추정`, `마지막 갱신 YYYY-MM-DD HH:MM` 표시 |
| 5 | **투자 시나리오 확장** | 종목마다 **판단 근거**, **1차 매수·추가 매수 기준**, **목표 가격**, **손절 가격**, **투자논리 훼손 조건**(영업적자 전환·부채비율 상한 돌파·현금흐름 적자 지속·핵심 업황/수주 훼손) 체크리스트와 전략 메모 |

## 계산 방식(투명성)

### 밸류에이션 — 3방식 가중

| 방식 | 계산 | 비고 |
| --- | --- | --- |
| PER | EPS × 목표 PER | 목표 PER은 섹터별(금융 8 · 자동차·조선 7.5 · 제조·철강 9 · 건설 9 · 통신·운송 10 · 유통·식품 12 · 원전·에너지 14 · 반도체 14 · 2차전지 18 · 인터넷·SW 20 · 바이오 24). **EPS ≤ 0 또는 영업적자면 완전 제외** |
| PBR | BPS × 목표 PBR | 목표 PBR도 섹터별(금융 0.65 ~ 바이오 3.0) |
| DCF | 5년 FCF 추정 + 영구가치 현재가치 ÷ 발행주식 수 | 할인율 **10%**, 영구성장률 **2%**, 성장률은 최근 매출증가율(±한도). 영업현금흐름(없으면 순이익) 기준 |

- 가중치 유형: 금융 PER 30%·PBR 60%·DCF 10% / 자산주 20·70·10 / 성장 45·15·40 / 제조 50·30·20
- 방식이 제외되면 **남은 방식끼리 100%로 재배분**하고, 화면에 `적용 가중치`와 제외 사유를 함께 표시
- **안전마진** = (적정가 − 현재가) / 적정가 × 100 · 적정가 밴드 = 하단 −10%, 상단 +15%
- EPS·BPS·현금흐름이 모두 없으면 적정가를 만들지 않고 "계산 불가"로 표시

### 재무상태 / 투자판단 분리

| 축 | 값 | 기준 |
| --- | --- | --- |
| 재무상태 | 🔴 영업적자 · 🟠 고부채(부채비율 >200%) · 🟡 재무주의(ROE<0·현금흐름<0·부채>150% 등) · 🟢 재무양호 · ⚪ 확인부족 | 기업의 재무 건전성만 |
| 투자판단 | 🟢 저평가(안전마진 ≥20%) · 🟡 적정(0~20%) · 🔴 고평가(<0%) + 매수검토/보유/신중 · ⚪ 판단보류 | 가격(적정가 대비)만 |

### 그 밖

- **1차 매수** = 적정가 −10%(현재가가 그보다 낮으면 현재가), **추가 매수** = 1차 −8%
- **목표가** = 현재가 +20%와 적정가 중 높은 값(최대 +60%), **손절** = 평단 −15%(미보유 시 현재가 −12%)
- **가치점수** = 저평가 35%(PER·PBR) + 수익성 25%(ROE·영업이익률) + 안정성 25%(부채비율·영업현금흐름) + 성장성 15%(매출·영업이익 증가율)
- **실현손익** = 매도대금 − 이동평균 원가(매수 기록이 없는 매도는 원가를 알 수 없으므로 제외하고 따로 경고)
- **총 순수익률** = (평가손익 + 실현손익 − 수수료·세금 + 배당) ÷ (보유 매입원금 + 매도원가)

## 저장소와 개인정보

- **보유종목·추천추적**은 v2와 똑같이 사용자의 비공개 구글 시트 `가치투자 포트폴리오 & 추천추적`에 저장됩니다(탭 구조 그대로, 변경 없음).
- **거래·배당·예수금·관심종목·전략·자산기록**은 로컬 `data/*.json`에 저장되고 `.gitignore`로 GitHub에 올라가지 않습니다. Streamlit Cloud는 재시작 시 파일이 초기화될 수 있어 **10번 메뉴에서 JSON/CSV로 백업**하는 것을 권장합니다.
- 기존 Apps Script가 임의 탭 이름을 지원하는 경우에만 Secrets에 `VI_EXTRA_SHEET = "1"`을 넣어 거래·배당·관심종목도 시트에 함께 남길 수 있습니다(실패하면 자동으로 로컬 저장).
- 공개 저장소에는 코드와 종목 유니버스(`data/universe.json`)만 있습니다. 개인 보유·거래 데이터는 올라가지 않습니다.

### Streamlit Cloud Secrets

```toml
GSHEET_WEBAPP_URL = "https://script.google.com/macros/s/.../exec"
GSHEET_TOKEN = "..."

# 선택 — AI 해설(없어도 정량 분석·차트·이슈 해석은 모두 동작)
OPENAI_API_KEY = "sk-..."
# GEMINI_API_KEY = "..."
# OPENROUTER_API_KEY = "..."
# VI_EXTRA_SHEET = "1"   # Apps Script가 임의 탭 이름을 지원할 때만
```

`GSHEET_WEBAPP_URL`이 없으면 보유종목·추천추적도 로컬 파일 모드로 동작합니다.
