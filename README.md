## 계산 방식(투명성)

### 밸류에이션 — 3방식 가중

| 방식 | 계산 | 비고 |
| --- | --- | --- |
| PER | EPS × 목표 PER | 목표 PER은 섹터별(금융 8 · 자동차·조선 7.5 · 제조·철강 9 · 건설 9 · 통신·운송 10 · 유통·식품 12 · 원전·에너지 14 · 반도체 14 · 2차전지 18 · 인터넷·SW 20 · 바이오 24) — 적자면 계산 불가 |
| PBR | BPS × 목표 PBR | 목표 PBR도 섹터별(금융 0.65 ~ 바이오 3.0) |
| DCF | 5년 FCF 추정 + 영구가치의 현재가치 ÷ 발행주식 수 | 할인율 **10%**, 영구성장률 **2%**, 성장률은 최근 매출증가율(±한도). 영업현금흐름(없으면 순이익)을 기준으로 하고 어떤 값을 썼는지 화면에 표시 |

- 가중치: 금융 PER 30%·PBR 60%·DCF 10% / 자산주 20·70·10 / 성장 45·15·40 / 제조 50·30·20
- 적정가 밴드: **하단 = 적정가 −10%**, **상단 = 적정가 +15%** → 4단계 대응 구간표
- EPS·BPS·현금흐름이 모두 없으면(적자 신규상장 등) 적정가를 만들지 않고 "계산 불가"로 표시합니다.

### 그 밖

- **상승 목표가** = 현재가 +20%와 적정가 중 높은 값(최대 +60%)
- **경계선** = 평단가 −15% (투자금 보존 원칙). 보유하지 않은 종목은 현재가 −12%
- **가치점수** = 저평가 35%(PER·PBR) + 수익성 25%(ROE·영업이익률) + 안정성 25%(부채비율·영업현금흐름) + 성장성 15%(매출·영업이익 증가율)
- 값이 없는 지표는 중립(50점), 확인 불가 항목이 2개 이상이면 **판정 보류**
- 스캔은 네이버 데이터만으로 조회(빠름). 영업현금흐름은 yfinance가 응답할 때만 채워지고, 없으면 "확인 불가"로 남깁니다.

## 저장소(포트폴리오·추천 기록)

이 앱은 **개인 보유 종목·수량·평단가를 GitHub에 올리지 않습니다.**
공개 저장소에는 코드와 종목 유니버스(`data/universe.json`, 공개 시세 기준 종목 목록)만 있고,
실제 데이터는 사용자의 구글 드라이브 비공개 시트 `가치투자 포트폴리오 & 추천추적`에 저장됩니다.

- 시트 탭: `보유종목`(종목코드·종목명·수량·평단가·메모), `추천추적`(등록일·종목코드·종목명·등록가·선정근거·목표가·경계가·상태메모)
- 앱 → Apps Script 웹 앱(비밀 토큰 검증) → 시트. 토큰은 Streamlit Secrets 에만 있습니다.

### Streamlit Cloud Secrets

```toml
GSHEET_WEBAPP_URL = "https://script.google.com/macros/s/.../exec"
GSHEET_TOKEN = "..."

# 선택 — AI 해설(없어도 정량 분석·차트·이슈 해석은 모두 동작)
OPENAI_API_KEY = "sk-..."
# GEMINI_API_KEY = "..."
# OPENROUTER_API_KEY = "..."
```

`GSHEET_WEBAPP_URL`이 없으면 로컬 파일 모드(`data/holdings.json`, `data/picks.json`)로 동작합니다.

## 로컬 실행

```bash
pip install -r requirements.txt

```

## 테스트

```bash
python3 -m py_compile app.py vi_core.py
python3 test_app.py
```

- 숫자·금액 파싱, 가치함정 필터, 가치점수, 3단 시나리오(원화/달러/적자/밸류에이션 연동)
- 저장소: 로컬 JSON 왕복, 구글 시트 웹 앱 모킹(GET/POST·토큰·한글 헤더·권한 오류)
- 종목명 검색(한글·티커·코드), 407종목 유니버스와 시장/섹터 필터
- 가격 흐름 파싱·20/60일선·52주 위치, 거시 지표 11종·시장 수급, 수급·배당·3~5년 재무 추이
- PER·PBR·DCF 3방식과 4단계 구간, 뉴스 분류(URL·시각 고정), 이슈→종목 영향 태그
- AppTest: 빈 상태 · 보유 표/차트/구간표/뉴스 · 스캔 → 상세 → 추천 등록 → 성적표 · 종목명 검색 분석 · 시트 모드

네트워크 없이 돌도록 모든 외부 호출을 대역으로 교체합니다.
