# 📈 가치투자 스튜디오

"저가 우량주를 찾고, 투자금을 잃지 않는 것"을 기준으로 **보유 종목 · 후보 종목 · 추천 기록**을
한 화면에서 점검하는 Streamlit 앱입니다.

- 앱: https://value-investor-studio.streamlit.app
- 저장소: https://github.com/can00319-tech/value-investor

## 4개 탭

| 탭 | 하는 일 |
| --- | --- |
| 🛡️ 보유 종목 & 시나리오 | 보유 종목의 현재가·평가손익·비중과 PER·PBR·부채비율·ROE를 한 표로 보고, 종목별 **상승/유지/경계 3단 시나리오**와 관련 뉴스를 확인합니다. 종목 추가·수정·삭제도 앱에서 바로 됩니다. |
| 🔍 저평가 우량주 발굴 | 원전·건설·바이오·반도체·금융·제조 대표 종목(한국+미국)과 직접 입력 종목에 **가치함정 필터**(영업현금흐름 양수, 영업이익 흑자, 부채비율 상한, 저PER·저PBR·ROE 하한)를 적용해 통과/탈락 사유와 **종합 가치점수(0~100)**를 보여줍니다. 통과 종목은 원클릭으로 추천 추적에 등록됩니다. |
| 🌐 이슈 & 종목 분석 | 국내외 주요 경제·증시 뉴스(RSS)를 주제별로 모아 관심 섹터 영향 포인트를 정리하고, 임의의 한국/미국 종목을 입력하면 재무 건전성 + 밸류에이션 + **3단 시나리오**를 만들어 줍니다. AI 키가 있으면 심층 리포트가 추가됩니다. |
| 📈 추천 추적 성적표 | 등록한 종목의 등록일·등록가·선정근거·목표/경계 기준을 저장하고, 현재가 대비 **누적 수익률**과 목표 달성(🎯)/경계 이탈(⚠️) 상태를 자동 추적합니다. |

## 계산 방식(투명성)

- **적정가** = (BPS × 1배 + EPS × 12배) 평균 — 장부가와 이익가치의 중간값
- **상승 목표가** = 현재가 +20%와 적정가 중 높은 값(최대 +60%)
- **경계선** = 평단가 −15% (투자금 보존 원칙). 보유하지 않은 종목은 현재가 −12%
- **가치점수** = 저평가 35%(PER·PBR) + 수익성 25%(ROE·영업이익률) + 안정성 25%(부채비율·영업현금흐름) + 성장성 15%(매출·영업이익 증가율)
- 값이 없는 지표는 중립(50점)으로 두고, 확인 불가 항목이 2개 이상이면 **판정 보류**로 표시합니다.
- 금융업은 부채비율·영업현금흐름 기준이 제조업과 비교되지 않는다는 안내를 함께 보여줍니다.

## 데이터 출처

| 용도 | 출처 |
| --- | --- |
| 한국 종목 시세·PER·PBR·EPS·BPS | 네이버 금융 (`m.stock.naver.com` API) |
| 한국 종목 재무(영업이익·ROE·부채비율·매출) | 네이버 금융 연간 재무제표 (확정 실적 열) |
| 영업현금흐름·미국 종목 재무 | yfinance, 야후 파이낸스 차트 API |
| 뉴스 | Google News RSS |
| 보유 종목·추천 기록 | 구글 시트(Apps Script 웹 앱) ←→ 로컬 JSON |

시세는 5분, 뉴스는 15분 캐시합니다. 외부 API가 막히면 해당 지표를 "확인 불가"로 표시하고 앱은 계속 동작합니다.

## 저장소(포트폴리오·추천 기록)

이 앱은 **개인 보유 종목·수량·평단가를 GitHub에 올리지 않습니다.**
공개 저장소에는 코드만 있고, 실제 데이터는 사용자의 구글 드라이브 비공개 시트
`가치투자 포트폴리오 & 추천추적`에 저장됩니다.

- 시트 탭: `보유종목`(종목코드·종목명·수량·평단가·메모), `추천추적`(등록일·종목코드·종목명·등록가·선정근거·목표가·경계가·상태메모)
- 앱 → Apps Script 웹 앱(비밀 토큰 검증) → 시트. 토큰은 Streamlit Secrets 에만 있습니다.

### Streamlit Cloud Secrets

```toml
GSHEET_WEBAPP_URL = "https://script.google.com/macros/s/.../exec"
GSHEET_TOKEN = "..."

# 선택 — AI 심층 리포트(없어도 정량 분석은 모두 동작)
OPENAI_API_KEY = "sk-..."
# GEMINI_API_KEY = "..."
# OPENROUTER_API_KEY = "..."
```

`GSHEET_WEBAPP_URL`이 없으면 로컬 파일 모드(`data/holdings.json`, `data/picks.json`)로 동작합니다.

## 로컬 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 테스트

```bash
python3 -m py_compile app.py vi_core.py
python3 test_app.py
```

- 가치함정 필터(가치함정·고부채·적자·데이터 없음·기준 완화), 가치점수, 3단 시나리오(원화/달러/적자)
- 저장소: 로컬 JSON 왕복, 구글 시트 웹 앱 모킹(GET/POST·토큰·한글 헤더·권한 오류·네트워크 오류)
- AppTest: 빈 상태 · 보유 종목 표/시나리오 카드 · 스캔 → 추천 등록 → 성적표 반영 · 시트 연동 표시
